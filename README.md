# SuPuja Creations Official Website (`supujacreations.com`)

Official website for **Sujit Kumar Gupta - Senior MIS & Business Automation Specialist** / **SuPuja Creations**.

## Tech Stack
- **Framework**: Next.js 15+ (App Router)
- **Styling**: Vanilla CSS tokens & utilities (`globals.css`)
- **Icons**: `lucide-react`
- **SEO & Schema**: JSON-LD ProfessionalService Schema, OpenGraph, Twitter Cards, Viewport configurations.

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser.

3. Build for Production:
```bash
npm run build
```

## Vercel Deployment & Domain Configuration

1. Push this folder to a GitHub repository (e.g. `supujacreations-website`).
2. Connect the repository to **Vercel**.
3. Under Project Settings -> **Domains**, add `supujacreations.com` and `www.supujacreations.com`.
4. Configure the DNS records (A record `@ -> 76.76.21.21` or CNAME `cname.vercel-dns.com`).
